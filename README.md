# HR Analytics Dashboard — Power BI

## Project Overview
An interactive HR Analytics Dashboard built using Microsoft Power BI to explore workforce composition, employee distribution, and attrition patterns.

## Objectives
- Monitor key employee KPIs.
- Analyse employee distribution across departments and other categories.
- Explore workforce patterns using interactive slicers.
- Present HR data through clear and informative visualisations.

## Dashboard Features
- 4 KPI cards
- 7 charts
- 4 interactive slicers
- Department and workforce analysis

## Tools Used
- Microsoft Power BI
- Power Query (if used)
- DAX (if used)
- HR Analytics dataset
